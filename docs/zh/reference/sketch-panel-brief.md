# 草图面板简报

每一拍在组装草图提示词之前都会先做一次分类，分类结果决定告诉分镜模型什么。

| 种类 | 触发条件 | 发给模型的面板文本 |
|---|---|---|
| 普通 | 默认 | 处理后的画面描述 |
| 黑场 | 描述含 黑场 / 黑屏 / 画面全黑 / 画面切黑 / 切黑 / 淡出至黑 / 全黑 | 纯黑面板，无景无人 |
| 字幕卡 | 描述含 屏幕出现文字 / 来源字幕 / 事实卡 / 标题卡 / 屏幕文字 / 字幕 / 片名 / 片尾 | 空白卡片，无可读文字 |
| 道具特写 | 没有具名角色且至少有一个 `[[道具]]` 标记 | 道具为唯一主体，并附道具参考图用于轮廓与比例 |

没有具名角色的面板会带 `[NO CHARACTERS]` 前缀；道具特写面板则改带 `[PROP INSERT]`。如果描述里写到人（人群、路人、游客、男人、女人等），则改为 `[UNNAMED PEOPLE ONLY]`，允许画灰色无名人偶。

## 道具形态锚点

草图提示词里的每条道具行都会带一段简短的形态锚点，取自道具设定的第一句（最多 80 字，去掉颜色词），例如 `FORM: 横向不规则山形寻迹牌，约 7 到 8 厘米宽，单手可握`。模型由此知道物体类别和尺度，又不会被材质细节干扰。

## 每拍自定义草图提示词

在分镜工作台的草图区展开 **草图提示词**。

- **追加**（默认）：你的文字接在处理后的描述之后，标为 `ADDITIONAL DIRECTION`。追加文本与描述走同一套处理：去掉颜色词、解析 `{{角色}}` / `[[道具]]` 标记、合并为单行。
- **覆盖**：直接替换描述。角色和道具标记仍从原画面描述解析。覆盖会取消自动的黑场 / 字幕卡判定，可用来纠正误判。

编辑框下方的预览显示种类徽标和最终提交的面板文本，与生成走同一份代码。

重新生成本集剧本会重建全部 beat 并清空每拍草图提示词；编辑单拍则会保留。

## 颜色词

草图阶段会去掉颜色形容词，保证标记色不被干扰。多字颜色词（鲜红、深蓝）总会去掉；单字颜色只有带 `色` / `的` 后缀时才去掉，所以“黄果树”这类地名和“黑场”这类镜头状态词会保留。场景名和道具名会自动受保护。

## 道具标记色

在拍里出现的全局道具会在生成或重生成草图时自动获得标记色；重新规划道具会保留已分配的颜色。
